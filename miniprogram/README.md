# 抓大鹅 - 微信小程序

一个参考《抓大鹅》游戏开发的微信小程序三消游戏。

## 游戏说明

### 核心玩法
- 点击锅里的物品，将其移到收集栏
- 收集栏满 7 个物品则游戏失败
- 三个相同物品自动消除并得分
- 消除所有物品即可通关

### 道具说明
- **❌ 移除**: 将收集栏前 3 个物品放回锅里
- **🍳 颠锅**: 重新排列锅里所有物品
- **🔀 洗牌**: 打乱物品位置
- **✨ 一步到位**: 自动添加匹配的物品

### 关卡配置
- 第 1 关: 45 个物品, 6 种类型, 180 秒
- 第 2 关: 60 个物品, 7 种类型, 200 秒
- 第 3 关: 75 个物品, 8 种类型, 220 秒
- 后续关卡: 逐级增加难度

## 测试方法

### 1. 安装微信开发者工具
下载地址: https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 2. 导入项目
1. 打开微信开发者工具
2. 点击 "导入项目" 或 "+"
3. 项目目录选择: `miniprogram` 文件夹
4. AppID 选择 "测试号"

### 3. 项目结构
```
miniprogram/
├── app.js              # 小程序入口
├── app.json            # 全局配置
├── app.wxss            # 全局样式
├── pages/
│   ├── index/          # 首页
│   │   ├── index.js
│   │   ├── index.wxml
│   │   ├── index.wxss
│   │   └── index.json
│   └── game/           # 游戏页
│       ├── game.js
│       ├── game.wxml
│       ├── game.wxss
│       └── game.json
└── utils/              # 工具类
    ├── audio-manager.js    # 音效管理
    └── performance-utils.js # 性能优化
```

### 4. 真机预览
- 在开发者工具中点击 "预览"
- 用微信扫描二维码
